---
name: Brand continuity
description: The identity constraint for TrafficSignal interface improvements
---

Improve TrafficSignal's presentation without replacing its existing color scheme, logo, brand name, or overall identity.

**Why:** The project owner explicitly asked for a clearer, more polished interface using the existing brand, not a rebrand.

**How to apply:** Reuse the existing theme and brand assets for UI improvements. Change the identity only when the user explicitly requests a rebrand.
